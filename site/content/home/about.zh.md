# 概要

13 年以上 iOS 开发经验，精通 Swift、SwiftUI 与 Objective-C，长期负责面向 C 端用户的产品迭代。
当前在 Nike 中国担任 Discover Squad 技术负责人，主导 **PDP**、ShopHome、Discover、Product Wall 等核心商品浏览页面，每日与 **Global 工程团队**协作，在大中华区落地差异化产品能力。
擅长端到端落地：从模糊的产品需求拆解出技术方案，推动跨团队执行，通过 Code Review 与结对带教工程师，并交付像素级精致的 UI 与流畅动效。
注重基础设施建设（网络层、路由、组件化），并已将 **Claude Code、Cursor 等 AI 辅助研发工具**深度融入技术设计、代码生成、调试与 Review 的日常工作流。
